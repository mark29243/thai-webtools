# Agentic OS — แผนที่ของ vault นี้

โฟลเดอร์นี้เป็นทั้ง Obsidian vault และ workspace ของ Claude Code
คุยกับผู้ใช้เป็นภาษาไทย เว้นแต่ผู้ใช้จะใช้ภาษาอื่น

## โครงสร้าง

| โฟลเดอร์ | ใส่อะไร | กฎ |
|---|---|---|
| `raw/` | ของดิบ: โน้ตที่จดเร็วๆ, ลิงก์, ข้อความที่ copy มา, ไฟล์จากลูกค้า | อ่านได้ ห้ามแก้หรือลบ |
| `wiki/` | ความรู้ที่เรียบเรียงแล้วและใช้ซ้ำได้ (ข้อมูลผู้ใช้, แหล่งหางาน, ราคา) | แก้ได้เมื่อผู้ใช้ขอหรือเมื่อ skill บอกให้แก้ |
| `outputs/` | ผลงานที่ Claude สร้าง แยกโฟลเดอร์ย่อยตามงาน | ตั้งชื่อไฟล์ `YYYY-MM-DD-หัวข้อ.md` หรือตามที่ skill กำหนด |
| `tools/` | สคริปต์สำหรับรันบน Windows | — |
| `.claude/skills/` | skill ของงานที่ทำซ้ำ | — |

## ไฟล์สำคัญใน wiki
- `wiki/profile.md` — ทักษะ ประสบการณ์ เรตราคา และงานที่ไม่รับ **อ่านไฟล์นี้ก่อนทำงานที่เกี่ยวกับผู้ใช้เสมอ**
- `wiki/job-sources.md` — เว็บและคำค้นที่ใช้หางาน

## Skills
- `job-hunt` — หางาน freelance ล่าสุดที่ตรงกับ `wiki/profile.md` แล้วสรุปลง `outputs/jobs/`

## กฎทั่วไป
- ห้ามสมัครงาน ส่งข้อความ หรือกรอกฟอร์มบนเว็บภายนอกแทนผู้ใช้ ทำได้แค่หาข้อมูลและร่างข้อความให้
- ห้ามแต่งข้อมูลขึ้นเอง ทุกงานที่รายงานต้องมีลิงก์ที่เจอจริง ถ้าไม่แน่ใจให้เขียนว่า "ยังไม่ได้ยืนยัน"
- ใช้ลิงก์แบบ Obsidian (`[[wiki/profile]]`) เมื่ออ้างถึงไฟล์ใน vault
