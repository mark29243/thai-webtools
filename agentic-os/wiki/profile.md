# โปรไฟล์ของฉัน

> แก้ไฟล์นี้ให้เป็นข้อมูลจริงของคุณ skill `job-hunt` ใช้ไฟล์นี้คัดงาน
> ส่วนที่มี (ตัวอย่าง) คือค่าที่ใส่ไว้ให้ก่อน ลบหรือแก้ได้เลย

## ทักษะหลัก (เรียงจากถนัดที่สุด)
- ทำเว็บด้วย Next.js / React / TypeScript (ตัวอย่าง)
- ทำเว็บเครื่องมือออนไลน์ (ตัวอย่าง)
- ใช้ AI ช่วยทำงาน: Claude Code, แชทบอท, ระบบอัตโนมัติ (ตัวอย่าง)

## ทักษะรอง
- แปลไทย ↔ อังกฤษ (ตัวอย่าง)
- เขียนคอนเทนต์ / สคริปต์วิดีโอ (ตัวอย่าง)

## ประเภทงานที่อยากได้
- งานจ้างเป็นโปรเจกต์ (fixed price) หรือรายชั่วโมง ทำทางไกลได้
- ภาษาที่สื่อสารกับลูกค้าได้: ไทย, อังกฤษ

## เรตราคาขั้นต่ำ
- งานโปรเจกต์: ไม่ต่ำกว่า 3,000 บาท (ตัวอย่าง)
- รายชั่วโมง: ไม่ต่ำกว่า $15/ชม. หรือ 400 บาท/ชม. (ตัวอย่าง)

## งานที่ไม่รับ
- งานปั่นรีวิว ปั่นยอด หรือสแปม
- งานที่ให้จ่ายเงินก่อนเริ่มงาน
- งานพนัน / ผิดกฎหมาย

## เว็บหางานที่ฉันมีบัญชีแล้ว
- (ใส่ชื่อเว็บ เช่น Fastwork, Upwork, Fiverr, LinkedIn)
