# แหล่งหางานและคำค้น

skill `job-hunt` ใช้รายการนี้ เพิ่มหรือลบได้ตามต้องการ

## เว็บ
| เว็บ | ประเภท | หมายเหตุ |
|---|---|---|
| fastwork.co | ฟรีแลนซ์ไทย | มีหน้า "งานประกาศ" ที่ผู้จ้างโพสต์ |
| upwork.com | ฟรีแลนซ์ต่างประเทศ | ค้นด้วยคำภาษาอังกฤษ |
| freelancer.com | ฟรีแลนซ์ต่างประเทศ | — |
| jobthai.com | งานไทย (มีงาน part-time/freelance) | — |
| linkedin.com/jobs | งานประจำ / contract | กรองแบบ Remote |
| remoteok.com, weworkremotely.com | งาน remote ต่างประเทศ | ส่วนใหญ่เป็นงานประจำ |

## คำค้น (ปรับตาม [[wiki/profile]])
- ไทย: `จ้างทำเว็บ`, `หาฟรีแลนซ์ ทำเว็บไซต์`, `จ้างทำแชทบอท LINE`, `จ้างแปลเอกสาร อังกฤษ`
- อังกฤษ: `Next.js freelance`, `React developer contract remote`, `AI chatbot developer freelance`, `Thai translator freelance`

## สัญญาณงานหลอก (ตัดทิ้ง)
- ให้จ่ายค่าสมัคร ค่าอุปกรณ์ หรือค่ามัดจำก่อนเริ่มงาน
- ให้ย้ายไปคุยใน Telegram / WhatsApp ทันทีโดยไม่ผ่านแพลตฟอร์ม
- ค่าตอบแทนสูงผิดปกติสำหรับงานง่ายๆ (เช่น กดไลก์ รีวิวสินค้า)
